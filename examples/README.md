# Ruby examples

Pure-Ruby examples for `dry-types`, provided by
[go-embedded-ruby](https://github.com/go-embedded-ruby/ruby) (rbgo). Run them
with the `rbgo` interpreter:

```sh
rbgo examples/dry_types_usage.rb
```

| File | Shows |
| --- | --- |
| [`dry_types_usage.rb`](dry_types_usage.rb) | `Dry::Types[...]` lookup, coercion/validation, combinators. |

Each example is executed as-is under rbgo (`require "dry-types"`).
